# Začíname

Fiškus je jeden program v dvoch podobách. Na vlastnom počítači beží ako
**desktop** — jedna firma, dáta iba u vás, funguje aj bez internetu. Na
serveri beží ako **webová aplikácia** — viac používateľov, prípadne viac
firiem, prístup z prehliadača. Kód, obrazovky aj výpočty sú rovnaké.

## Ako sa v programe orientovať

Menu vľavo je zoradené tak, ako doklad putuje firmou: **Predaj → Nákup →
Peniaze → Dane → Účtovníctvo**. Na mobile sa menu schová pod tlačidlo
vľavo hore.

| Skratka | Kde funguje | Čo urobí |
|---|---|---|
| `N` | zoznamy | nový doklad alebo položka |
| `Ctrl + S` | formuláre | uloží |
| `Esc` | panel s detailom | zavrie panel |

Každý zoznam má hľadanie (bez diakritiky, viac slov naraz — „nitra 2026“)
a export do Excelu a CSV. Exportuje sa presne to, čo vidíte po filtri.
